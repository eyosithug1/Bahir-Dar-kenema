STEP BY STEP TO GET STARTED
===========================

Step 1: Download
   - Download BDK_FullStack folder from outputs
   - Extract on your computer

Step 2: Setup Backend
   - Open terminal in BDK_FullStack/backend
   - Run: npm install
   - Create .env file: cp .env.example .env
   - Edit .env and add your MongoDB URI
   - Run: npm run dev
   - See: "BDK API server running on port 5000"

Step 3: Setup Frontend (new terminal)
   - Navigate to BDK_FullStack/frontend
   - Run: npm install
   - Run: npm run dev
   - Opens automatically at http://localhost:3000

Step 4: Test
   - Click "Create Account"

WHAT IF SOMETHING BREAKS?
=========================

Check these in order:
1. Is backend running? (npm run dev in backend folder)
2. Is frontend running? (npm run dev in frontend folder)
3. Is MongoDB connected? (Check .env file)
4. Browser console errors? (Press F12)
5. Network tab? (Check API responses)
6. Backend logs? (Watch terminal)

Most issues are:
- Missing .env file
- Backend not running
- MongoDB connection wrong
- Missing npm install
